# AI-Based Disease Prediction System Using Machine Learning

A Python-based Artificial Intelligence project that predicts possible diseases based on user-selected symptoms using a Machine Learning classification algorithm.

The system uses a **Random Forest Classifier** to analyze symptom patterns and provide a predicted disease through a simple and user-friendly **Tkinter graphical interface**.

---

## 📌 Project Overview

The AI-Based Disease Prediction System demonstrates the practical application of Machine Learning in the healthcare domain.

The user selects symptoms such as fever, cough, headache, and fatigue. The system processes these inputs and uses a trained machine learning model to predict the most likely disease.

This project is developed for educational purposes to understand AI concepts such as:

- Machine Learning
- Supervised Learning
- Classification
- Model Training
- Prediction

---

## 🚀 Features

- ✅ Machine Learning based disease prediction
- ✅ Random Forest Classification algorithm
- ✅ Symptom-based input system
- ✅ Tkinter graphical user interface
- ✅ Real-time prediction
- ✅ Model accuracy evaluation
- ✅ Single-file implementation
